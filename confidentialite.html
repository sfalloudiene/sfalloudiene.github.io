Ce site est un site perso, sans régie publicitaire ni revente de données. Voici simplement ce qui est utilisé et pourquoi.

Mesure d'audience

Le site utilise Google Analytics (GA4) pour savoir, de façon globale, combien de personnes visitent le site et quelles pages sont lues. L'anonymisation de l'IP est activée. Cela peut déposer des cookies de mesure d'audience dans votre navigateur. Vous pouvez bloquer ces cookies via les réglages de votre navigateur ou une extension de blocage sans que ça n'affecte l'usage du site.

Commentaires

Les commentaires sous les articles sont gérés par Giscus, qui s'appuie sur les Discussions GitHub. Pour commenter, vous devez vous connecter avec un compte GitHub : le commentaire est alors stocké sur GitHub, pas sur ce site. La politique de confidentialité de GitHub s'applique à ces données.

Newsletter

L'inscription à la newsletter se fait via Buttondown, qui stocke votre adresse email pour l'envoi des notes publiées. Chaque email contient un lien de désabonnement immédiat, qui supprime votre adresse de la liste. Voir la politique de confidentialité de Buttondown.

Contact
